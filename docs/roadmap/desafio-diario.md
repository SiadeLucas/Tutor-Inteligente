# Desafio Diário (Daily Challenge)

Módulo de engajamento diário e desenvolvimento do raciocínio matemático avançado.

## Visão Geral

- **1 Questão Diária Inédita**: Todo dia uma questão provocativa é lançada para toda a comunidade de alunos.
- **Raciocínio Matemático Elegante**: Foco em problemas de olimpíadas (OBMEP, Canguru) ou aplicações criativas dos teoremas do Iezzi.
- **Sequência de Dias Ativos (Streaks)**: Integração com o sistema de gamificação para recompensar a consistência diária de estudo.
- **Fórum de Soluções Criativas**: Espaço para discutir diferentes abordagens e demonstrações alternativas entre alunos.
