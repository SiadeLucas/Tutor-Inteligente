# Tutor Inteligente - Documentação do Projeto

Este é um sistema de Planejamento e Gestão de E-learning projetado para oferecer uma experiência de aprendizado personalizada e eficiente em Matemática do 2º Grau.

## 📋 Sobre o Projeto

O Tutor Inteligente é uma plataforma EAD completa que gerencia desde o conhecimento pedagógico e suas relações até a execução de aulas, atividades e avaliações.

### Principais Funcionalidades:
- 🧠 **Gestão de Conhecimento**: Base de conteúdo estruturada com taxonomia e relações.
- 🎯 **Planejamento Didático**: Geração de planos de ensino baseados em regras de negócio.
- 👥 **Módulos Completos**:
  - Onboarding de Usuários
  - Interface e Usabilidade
  - Pagamentos
  - Conteúdo Pedagógico
  - Autenticação
  - Controle de Progresso e Desempenho
  - Exercícios e Avaliações
  - Painel do Professor
- 📊 **Sistemas de Análise**: Ferramentas para acompanhamento e métricas.

## 🚀 Como Executar

Para visualizar a documentação localmente, utilize o servidor de desenvolvimento do MkDocs.

```bash
# Instalar dependências (se necessário)
pip install -r requirements.txt

# Iniciar o servidor de desenvolvimento
mkdocs serve
```

Acesse a documentação em [http://127.0.0.1:8000](http://127.0.0.1:8000).

## 📂 Estrutura do Projeto

- `docs/`: Contém toda a documentação do projeto.
  - `knowledge/`: Base de conhecimento pedagógico.
  - `modules/`: Documentação detalhada de cada módulo do sistema.
  - `systems/`: Descrição dos sistemas de análise.
  - `roadmap/`: Visão futura do projeto.
  - `index.md`: Página inicial.
