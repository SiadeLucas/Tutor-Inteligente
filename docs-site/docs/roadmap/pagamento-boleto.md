# Pagamento via Boleto Bancário

Opção complementar de faturamento bancário para inclusão de estudantes desbancarizados.

## Visão Geral

- **Emissão com Código de Barras e Linha Digitável**: Geração de boleto em PDF para pagamento em casas lotéricas ou internet banking.
- **Conciliação Automatizada (D+1 a D+3)**: Webhook de compensação que ativa a vigência de 12 meses assim que o valor for liquidado pelo banco.
- **Régua de Lembretes**: Envio de notificações por e-mail no dia do vencimento para reduzir o abandono de pedidos.
