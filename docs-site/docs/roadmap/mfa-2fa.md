# Autenticação em Dois Fatores (2FA / MFA)

Camada adicional de proteção cibernética para o acesso à plataforma.

## Visão Geral

- **Suporte a TOTP (Google Authenticator / Authy)**: Geração de códigos temporários a cada 30 segundos.
- **Obrigatoriedade para Perfil Professor**: Proteção reforçada para a conta docente que controla notas, finanças e curadoria.
- **Códigos de Backup de Emergência**: Lista de chaves de recuperação descartáveis para redefinição de acesso em caso de perda de aparelho.
