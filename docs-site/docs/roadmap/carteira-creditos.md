# Carteira Digital de Créditos

Sistema de saldo pré-pago para compras imediatas de capítulos de 50 minutos.

## Visão Geral

- **Pacotes de Fichas / Créditos**: Aquisição com desconto de pacotes (ex: *Pacote 5 Aulas de 50 min*, *Pacote 10 Aulas de 50 min*).
- **Desbloqueio em 1 Toque**: O aluno consome 1 crédito da sua carteira para liberar instantaneamente o capítulo que precisa estudar no momento, sem passar pelo checkout a cada compra.
- **Extrato de Saldo e Recarga Automática**: Histórico visual de créditos utilizados e opção de recarga programada.
